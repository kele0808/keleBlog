## 房价预测案例

### 数据集

| 面积(m²) | 总价(万元) |
|---|---|
| 50 | 122 |
| 70 | 157 |
| 90 | 203 |
| 110 | 255 |
| 130 | 303 |

问题：预测 100 平方米的房价。

### 可视化

```python
import matplotlib.pyplot as plt

# 1 准备数据
area = [50, 70, 90, 110, 130]      # 面积 m^2
price = [122, 157, 203, 255, 303]  # 总价 万元

# 2 画散点图
plt.figure(figsize=(8, 6))
plt.scatter(area, price, color='blue', s=80)

# 3 设置坐标轴
plt.xlabel('面积(m^2)')
plt.ylabel('总价(万元)')
plt.show()
```

### 趋势线

尝试画一条直线尽量穿过所有数据点，用它描述面积和总价的关系。直线方程可能是 \(price = area \times 2.2 + 10\)。代入 100 平方米，算得总价 230 万元。

## 线性回归

**线性回归**（Linear Regression）是机器学习最经典的模型之一：通过构建线性方程来拟合数据的内在分布规律，实现对连续数值的预测。

### 线性

- 线性 \(\ne\) 直线
- 齐次性：\(f(ax) = a \cdot f(x)\)
- 可加性：\(f(x + y) = f(x) + f(y)\)
- 几何解释：一维空间中线性关系是一条直线；高维空间中是平面或超平面

> **补充**
> 严格说，\(\hat{y} = wx + b\) 在 \(b \ne 0\) 时是「仿射函数」，不满足上面的齐次性。机器学习里说「线性回归」，指的是 **模型对参数 \(w, b\) 是线性的**。这个区别在后面讲多项式回归时会用到。

### 回归

**回归**（Regression）一词源于统计学家高尔顿（Francis Galton）的研究：身高极高或极矮的父母，子女身高常向群体均值靠拢，称为「回归均值」。

在机器学习中，回归被引申为：通过数据建模变量间的映射关系，实现对连续数值的预测。

### 模型公式

最简单的线性回归只有一个特征：

{{< math >}}
\hat{y} = wx + b
{{< /math >}}

- \(\hat{y}\)：模型输出的预测值
- \(x\)：输入模型的特征值
- \(w\)：权重（weight），也称斜率（slope）
- \(b\)：偏置（bias），也称截距（intercept）

\(w\) 和 \(b\) 是模型需要学习的参数。训练模型就是寻找一组最合适的 \(w\) 和 \(b\)。

## 损失函数：度量模型偏差

**损失函数**（Loss Function）用于评估模型参数，度量预测值与真实值之间的偏差。预测离真实越远，损失越大。模型训练要让损失函数尽量小。

回归最常用 **均方误差**（Mean Squared Error, MSE）：

{{< math >}}
MSE = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2
{{< /math >}}

1. 计算每个样本的误差（预测值 − 真实值）
2. 对误差取平方，消除正负号、放大极端误差
3. 对所有样本求平均

## 梯度下降：寻找最优参数

**梯度下降**（Gradient Descent）沿着损失函数下降最快的方向，逐步调整参数，直至找到最优解。

循环步骤：计算梯度 → 更新参数 → 迭代优化 → 模型收敛。

用蒙眼下山来比喻：

- 当前海拔，对应 **损失**（Loss）
- 下坡方向，对应 **梯度**（Gradient）
- 下山步幅，对应 **学习率**（Learning Rate）

训练流程：

1. 输入特征值
2. 输出预测值
3. 计算损失
4. 计算梯度
5. 更新参数

每轮循环都在优化参数，模型经过多轮迭代逐渐收敛到最优解。细节放在下一章。

## 多特征线性回归

给房价额外引入其他特征：楼层、地铁距离、房龄。

| 面积(m²) | 楼层 | 地铁距离(km) | 房龄(年) | 总价(万元) |
|---|---|---|---|---|
| 50 | 3 | 0.5 | 5 | 180 |
| 70 | 15 | 1.2 | 10 | 210 |
| 90 | 8 | 0.3 | 2 | 320 |
| 110 | 20 | 2.0 | 15 | 280 |
| 130 | 12 | 0.8 | 8 | 380 |

### 扩展模型

有 \(d\) 个特征时：

{{< math >}}
\hat{y} = w_1 x_1 + w_2 x_2 + w_3 x_3 + \cdots + w_d x_d + b
{{< /math >}}

{{< math >}}
\hat{y} = w_1 \cdot x_{\text{面积}} + w_2 \cdot x_{\text{楼层}} + w_3 \cdot x_{\text{地铁距离}} + w_4 \cdot x_{\text{房龄}} + b
{{< /math >}}

对权重的直觉预期：

- \(w_1\)（面积）：正相关，越大越贵
- \(w_2\)（楼层）：正相关，越高越贵
- \(w_3\)（地铁距离）：负相关，越近越贵
- \(w_4\)（房龄）：负相关，越新越贵

### 代码实现

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 1 准备数据：面积，楼层，地铁距离，房龄
X = np.array([
    [ 50,  3, 0.5,  5],
    [ 70, 15, 1.2, 10],
    [ 90,  8, 0.3,  2],
    [110, 20, 2.0, 15],
    [130, 12, 0.8,  8],
])
y = np.array([180, 210, 320, 280, 380])  # 总价(万元)

# 2 训练模型
model = LinearRegression()
model.fit(X, y)

# 3 查看参数
feature_names = ['面积', '楼层', '地铁距离', '房龄']
print("各项特征权重: ")
for name, w in zip(feature_names, model.coef_):
    print(f"  {name}: {w:+.2f}")
print(f"  偏置 b: {model.intercept_:.2f}")

# 4 预测新房 [100, 10, 0.6, 5]
new_house = np.array([[100, 10, 0.6, 5]])
pred = model.predict(new_house)
print(f"\n预测房价: {pred[0]:.1f} 万元")
```

> **补充**
> 这里只有 5 个样本、5 个参数（4 个权重 + 1 个偏置），方程组刚好有唯一解，模型会「完美」穿过所有点。这是演示，真实场景样本远多于参数，模型只能近似拟合。

## 向量表示

{{< math >}}
\hat{y} = w^{\top} x + b
{{< /math >}}

其中

{{< math >}}
x =
\begin{bmatrix}
x_1 \\ x_2 \\ \vdots \\ x_d
\end{bmatrix},
\quad
w =
\begin{bmatrix}
w_1 \\ w_2 \\ \vdots \\ w_d
\end{bmatrix}
{{< /math >}}

### 多项式回归

引入多项式回归用于曲线拟合：

{{< math >}}
\hat{y} = w_1 x + w_2 x^2 + \cdots + w_d x^d + b
{{< /math >}}

- \(d = 1\)：普通线性回归
- \(d = 2\)：拟合抛物线
- 阶数 \(d\) 越高，曲线越灵活

尽管特征（\(x^2, x^3\)）出现了高阶非线性项，模型对参数（\(w_1, \ldots, w_d, b\)）仍然是线性的：\(\hat{y}\) 是这些参数的线性组合。因此 **多项式回归本质上仍是线性模型**，可以用线性回归的方法求解。把 \(x^2\) 看成一个新特征就行。

## 逻辑回归与深度学习

线性回归延伸出两个重要方向。

**1. 逻辑回归：线性回归 + 激活函数**，用于解决分类问题，输出概率：

{{< math >}}
\begin{aligned}
P(y = 1 \mid x) &= \sigma(wx + b) \\
&= \frac{1}{1 + e^{-(wx + b)}}
\end{aligned}
{{< /math >}}

**2. 深度学习：多层「线性变换 + 激活函数」的叠加**，逐层堆叠构成神经网络：

{{< math >}}
\text{输入} \xrightarrow{\text{线性 + 激活}} \text{隐藏层}_1 \xrightarrow{\text{线性 + 激活}} \text{隐藏层}_2 \rightarrow \cdots \rightarrow \text{输出}
{{< /math >}}

> **补充**
> 常有人说「深度学习 = 多层逻辑回归叠加」，这在结构上是对的（每层都是线性 + 非线性），但现代网络的隐藏层大多用 ReLU 等激活函数而不是 Sigmoid，Sigmoid / Softmax 主要留在输出层。

## 总结

线性回归包含了机器学习的核心思想：

1. 用数据寻找规律
2. 用模型表达规律
3. 用损失函数衡量误差
4. 用梯度下降优化参数
5. 循环训练，迭代出更准确的模型

几乎所有机器学习和深度学习模型，都是对这个基本范式的扩展和升级。
