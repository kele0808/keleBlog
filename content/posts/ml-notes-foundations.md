这篇是我最近学机器学习时的笔记整理。公式会有，但重点是先把一条主线理清：

**模型在拟合数据里的规律；对参数化模型来说，学习过程就是找到一组让损失更小的权重。**

---

## 机器学习在研究什么

更准确的说法不是「预测未来」，而是：

> 让计算机从数据中学习规律，而不是靠人把规则一条条写死。

Arthur Samuel 的经典表述是：让计算机在**无需显式编程**的情况下获得能力。工程上可以看成：从数据里学一个映射 \(f(x) \approx y\)，用来预测或决策。

传统机器学习和深度学习常被这样对比：

| | 传统机器学习 | 深度学习 |
|---|---|---|
| 特征 | 多半要人工设计 | 网络自己抽层次化特征 |
| 数据形态 | 更擅长结构化 / 表格数据 | 更擅长图像、文本、语音等非结构化数据 |
| 标注 | **监督学习**依赖人工标注 | 同样可以监督；也能自监督 |
| 模型 | 线性模型、树模型等 | 多层神经网络 |

两点容易写偏：

- 「依赖人工标注」只适用于**监督学习**，不是机器学习的全部。无监督、自监督都不靠完整的人工标签。
- 「结构化数据」是传统方法的常见战场，不是机器学习的定义。

深度学习是机器学习的一个子领域：用多层神经网络做表示学习，自动提取更深的抽象特征。

## 模型到底是什么

**模型**本质上是从大量数据里学到的一个函数，把输入映射成输出。说成「一套规则」也可以，但别理解成 if-else；线性模型、神经网络里的「规则」是权重和偏置。

几个基本术语：

- **数据集（dataset）**：全部样本
- **数据点 / 样本（data point）**：其中一条记录
- **特征（feature）**：用来描述样本的输入变量
- **标签（label）**：监督学习里要预测的目标

不同特征通常对应不同权重：重要的特征权重大，噪声特征权重应接近 0。

「机器学习的本质是寻找最优权重」——这句话对**参数化模型**（线性回归、逻辑回归、神经网络）成立。k-NN、决策树并不是在维护一组 \(w\)，归纳方式不同。

---

## 机器学习的三类问题

### 1. 监督学习

数据有标签，目标是学会 \(x \rightarrow y\)。

- **回归**：\(y\) 是连续数值，比如房价、温度
- **分类**：\(y\) 是离散类别，比如垃圾邮件 / 正常邮件

### 2. 无监督学习

数据没有标签，目标是发现结构。

- **聚类**：按相似度把行为接近的样本放进同一组
- **降维**：特征太多时，尽量少丢关键信息，把数据变简单
- **生成模型**：学习数据分布，再采样出新样本

生成模型可以做 AIGC，但不要把 AIGC 全部等同于无监督。现在的大语言模型主要是**自监督**：用数据自身构造标签（比如根据上文预测下一个 token）。

### 3. 强化学习

智能体在环境里不断试错，根据奖励学习更优的**策略和动作**（不是「角色」）。监督是「看标准答案」，强化是「做了才知道好坏」。

## 线性回归：对参数线性

线性回归用来建模输入到**连续值**的映射。单特征时，预测值写作：

{{< math >}}
\hat{y} = xw + b
{{< /math >}}

多个特征：

{{< math >}}
\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_d x_d + b = w^{\top} x + b
{{< /math >}}

这里的「线性」指的是**对参数 \(w, b\) 线性**，不是对原始 \(x\) 不能做变换。把 \(x^2\)、\(x_1 x_2\) 当成新特征送进去，仍然可以叫线性回归（多项式回归就是这样）。

---

## 损失函数与梯度下降

模型先猜，再用**损失函数**衡量预测和真实值的偏差。回归最常用 **均方误差 MSE**：

{{< math >}}
L = \mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2
{{< /math >}}

**梯度下降**沿着损失下降最快的方向调整参数。对 \(w\) 求导（\(\hat{y}_i = w x_i\)，或对 \(w\) 的对应分量）：

{{< math >}}
\frac{\partial L}{\partial w}
=
\frac{2}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)x_i
{{< /math >}}

更新规则：

{{< math >}}
w \leftarrow w - \eta \frac{\partial L}{\partial w}
{{< /math >}}

- \(w\)：模型参数
- \(L\)：损失
- \(\partial L / \partial w\)：梯度
- \(\eta\)：学习率（learning rate）

有人把 MSE 写成 \(\frac{1}{2n}\sum(\cdot)^2\)，导数里的 2 会消掉。两种写法等价，只是差一个常数倍。

一轮训练可以看成：

> 输入数据 → 计算预测 → 计算损失 → 计算梯度 → 更新参数 → 重复

学习率要合适：

- 太大：参数来回震荡，甚至发散
- 太小：收敛极慢

「梯度爆炸」更常用来描述深度网络里反向传播时梯度数值炸掉。学习率过大和学习率无关的梯度爆炸，不是同一件事。

### 优化算法

朴素梯度下降之后，常见改进：

- **动量法（Momentum）**：带上历史速度，减少震荡
- **AdaGrad**：每个参数维护独立的学习率；累计平方梯度，后期可能衰减过快
- **RMSProp**：用近期梯度的指数滑动平均，避免 AdaGrad 把学习率扼死
- **Adam**：动量 + RMSProp，目前最常见的默认优化器

## 数据预处理

一条很重要、也很容易忘的原则：

> **先划分数据集，再做预处理。**

均值、标准差、独热编码的类别、缺失值填充规则，都只应在**训练集**上拟合，再应用到验证集和测试集。否则测试信息会泄漏进训练过程，分数会虚高。

常见划分：

- **训练集**：约 60%–80%，用来学参数
- **验证集**：约 10%–20%，用来调超参、做早停
- **测试集**：约 10%–20%，只在最后评估一次

数据很少时，用 K 折交叉验证往往比死守这个比例更稳。

### 缺失值

按缺失比例（经验规则，不是铁律）：

- 很少（比如 < 5%）：可以删缺失行
- 极多（比如 > 70%）：考虑删掉这一列，信息已经剩不下多少

按特征类型：

- 数值：填均值或中位数（有异常值时中位数更稳）
- 类别：填众数，或单独做成 `unknown`

### 特征编码

模型要做数值计算，类别文本得先变成数。

- **序数编码**：类别本身有顺序。低 = 0，中 = 1，高 = 2
- **独热编码（one-hot）**：每个类别变成独立的 0/1 列，避免把「无序类别」当成有大小关系。代价是类别一多就会**维度爆炸**
- **标签编码（label encoding）**：把类别映射成整数。二分类没问题；多分类无序变量用它，会引入虚假的序关系，线性模型会吃亏。树模型对这种整数编码相对不敏感

### 特征缩放

量纲差很大时（如收入 vs 年龄），梯度方法和距离方法会被大数值特征主导。

- **标准化**：\(\dfrac{x - \mu}{\sigma}\)，变成均值 0、方差 1
- **归一化**：压到固定区间，通常是 \([0, 1]\)

线性回归、逻辑回归、K-Means、PCA、神经网络通常需要缩放；**树模型一般不需要**。

## 模型评估

先把一个很弱的 **Baseline** 跑起来（预测均值、线性模型、简单规则）。后面所有花活都要先超过它，才说明有价值。

回归常用指标：

| 指标 | 含义 |
|---|---|
| **MAE** 平均绝对误差 | \(\frac{1}{n}\sum \|y_i - \hat{y}_i\|\)，好解释，单位和 \(y\) 相同 |
| **MSE** 均方误差 | 平方后放大较大误差，无正负 |
| **RMSE** 均方根误差 | MSE 开方，单位回到 \(y\) 的量纲 |
| **\(R^2\)** 决定系数 | 相对「预测均值」解释了多少方差，越接近 1 越好；可以是负数，表示还不如猜均值 |

**残差** = 真实值 − 预测值。看残差图能发现非线性、异方差等问题。

**K 折交叉验证**：把数据切成 K 份，轮流拿一份当验证集。数据不多时，比单次划分更稳。

## 欠拟合和过拟合

**欠拟合**：模型太简单，训练集都学不像。

- 加多项式等高次项
- 组合特征
- 提高模型复杂度
- 训练更久、换更强的模型

**过拟合**：训练集分数很高，验证/测试很差。模型把噪声也背下来了。

- 增加训练数据
- **正则化**：在损失里惩罚过大的权重
- 降低模型复杂度
- 特征选择，去掉干扰信号
- **早停**：验证损失开始变差就停

普通 MSE：

{{< math >}}
L(w) = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2
{{< /math >}}

加上正则：

{{< math >}}
L_2(w) = \mathrm{MSE} + \lambda \|w\|_2^2
{{< /math >}}

{{< math >}}
L_1(w) = \mathrm{MSE} + \lambda \|w\|_1
{{< /math >}}

- **L2**：惩罚权重平方和，权重会被压小，但不一定到 0（Ridge）
- **L1**：惩罚绝对值之和，容易把部分权重压成 0，相当于在做特征选择（Lasso）

\(\lambda\) 越大，惩罚越狠，模型越「不敢」复杂。

## 逻辑回归：线性模型 + Sigmoid

线性回归输出连续值。很多问题是选择题：属于哪一类？

**逻辑回归**把线性输出压到 \((0, 1)\)，当成正类概率。核心是 Sigmoid：

{{< math >}}
\sigma(z) = \frac{1}{1 + e^{-z}}
{{< /math >}}

{{< math >}}
\hat{y} = \sigma(w^{\top} x + b) = \frac{1}{1 + e^{-(w^{\top} x + b)}}
{{< /math >}}

{{< math >}}
P(y = 1 \mid x) = \hat{y}
{{< /math >}}

数据流可以看成：

{{< math >}}
x \;\xrightarrow{w^{\top}x+b}\; z \;\xrightarrow{\sigma}\; P(y=1\mid x)
{{< /math >}}

Sigmoid 求导很干净：

{{< math >}}
\sigma'(z) = \sigma(z)\bigl(1 - \sigma(z)\bigr)
{{< /math >}}

所以：**逻辑回归 = 线性回归 + Sigmoid**。它仍然是线性分类器，决策边界是一张超平面。

深度学习可以粗看成多层「线性变换 + 非线性激活」的叠加。逻辑回归是其中一层（线性 + Sigmoid）。现代网络更常用 ReLU 等激活，并不只是把逻辑回归叠很多层。

分类一般不用 MSE，而用**交叉熵**：

{{< math >}}
L(w,b)
=
-\frac{1}{m}
\sum_{i=1}^{m}
\Bigl[
y_i\log\hat{y}_i
+
(1-y_i)\log(1-\hat{y}_i)
\Bigr]
{{< /math >}}

对 Sigmoid 的输入 \(z\) 求导后有一个很漂亮的结果：

{{< math >}}
\frac{\partial L}{\partial z} = \hat{y} - y
{{< /math >}}

和线性回归残差长得很像，实现时梯度很好写。

## 分类指标

混淆矩阵（列是真实情况，行是预测）：

| | 真实正类 | 真实负类 |
|---|---|---|
| **预测正类** | TP | FP |
| **预测负类** | FN | TN |

- **准确率 Accuracy** \(\dfrac{TP+TN}{TP+TN+FP+FN}\)：整体对了多少。类别极不均衡时会骗人（99% 负类，全猜负类也有 99% 准确率）。
- **精确率 Precision** \(\dfrac{TP}{TP+FP}\)：我报出来的正类里，有多少是真的。
- **召回率 Recall** \(\dfrac{TP}{TP+FN}\)：所有真正的正类里，我找出了多少。
- **F1** 是 Precision 和 Recall 的调和平均，两者都要时常用它。

宁可漏报也别误报（垃圾邮件进收件箱），看 Precision；宁可误报也别漏（癌症筛查），看 Recall。

## 决策树、随机森林与 Boosting

### 决策树：怎么选分裂特征

每次分裂都想让子节点更「纯」。常用两种不纯度：

- **信息增益** = 分裂前的熵 − 分裂后的加权熵。增益越大越好
- **基尼系数**

{{< math >}}
\mathrm{Gini} = 1 - \sum_{k=1}^{K} p_k^2
{{< /math >}}

基尼越小，数据越纯。CART 常用基尼。

决策树很容易过拟合，需要**剪枝**：

- **预剪枝**：分裂前就限制深度、叶子最小样本数等
- **后剪枝**：先长完整棵树，再往回砍掉不划算的枝

### 随机森林：Bagging

随机森林 = 大量决策树的集成。两处随机：

1. **有放回抽样（bootstrap）** 得到各棵树的训练集
2. 每次分裂只看**随机特征子集**，不看全部特征

**Bagging** 的思路是：一群模型平行训练，预测时少数服从多数（分类）或取平均（回归）。随机森林是最典型的 Bagging。

### Boosting：接力纠错

Boosting 是串行的：后面的模型专门补前面的错。

注意：不是所有 Boosting 都在「拟合残差」。

- **AdaBoost**：把分错的样本权重调高
- **GBDT（梯度提升树）**：每一棵新树拟合当前损失的**负梯度**

{{< math >}}
r_{im}
=
-
\left[
\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}
\right]_{F=F_{m-1}}
{{< /math >}}

{{< math >}}
F_m(x) = F_{m-1}(x) + \eta \, h_m(x)
{{< /math >}}

当损失是平方误差时，负梯度正好等于残差：

{{< math >}}
r_i = y_i - F(x_i)
{{< /math >}}

换交叉熵等损失，残差就不再是简单的 \(y - \hat{y}\)，而是对应损失的负梯度。

## 无监督学习：聚类与降维

### K-Means

把无标签数据自动分成 **K 个簇**。K 是**预先指定**的簇数，Means 是均值（质心）。

算法步骤：

1. 初始化 K 个质心
2. 每个样本分给最近的质心
3. 用簇内样本均值更新质心
4. 重复 2–3，直到质心几乎不动，或到最大轮数

随机初始化可能陷入较差的局部最优，所以有 **K-Means++**：第一个质心随机选，后面的质心更倾向离现有质心远的点。它解决的是**初始化**，不是怎么选 K。

选 K 常用**肘部法则**：依次试不同的 K，画 SSE（簇内平方误差和）。K 增大时 SSE 会持续下降，在下降变缓的「肘点」附近选 K。

聚类常见用途：客户分群、作为推荐系统的中间特征。

### 特征太多时：降维

维度过高会带来**维度灾难**：数据变稀疏、距离失效、容易过拟合、计算变贵。

两类做法：

- **特征选择**：丢掉不重要的原始特征。正则化、方差阈值都算
- **特征提取**：把原始特征组合成新的、更少的特征

**PCA（主成分分析）**属于特征提取：找到方差最大的方向，把高维数据投影到低维空间。目标是压缩维度的同时，尽量保留信息（方差）。
