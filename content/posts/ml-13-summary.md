## 机器学习全景

三类任务：

1. **监督学习**：有标签，学习从输入到答案的映射
   - 回归：房价、销量、温度
   - 分类：垃圾邮件、流失预测
   - 线性 / 逻辑回归、树模型、KNN、SVM
2. **无监督学习**：无标签，发现数据自身的结构
   - 聚类：K-Means、DBSCAN
   - 降维：PCA、特征提取
   - 异常检测、生成建模
3. **强化学习**：在动态环境中试错，用奖惩塑造策略
   - Agent / Environment
   - Action / Reward / Policy
   - 游戏、机器人、推荐策略

三类任务共享同一套解决问题的流程：

1. 定义目标与指标
2. 清洗数据与特征
3. 训练、验证、测试
4. 处理拟合问题
5. 上线监控与重训

> **提示**
> 机器学习不是算法清单，是「用数据解决问题」的完整工程方法。

## 核心概念

### 机器学习在学什么

- **传统编程**：人工阐明规则，机器按规则执行。规则 + 数据 → 结果
- **机器学习**：给机器历史样本，让它自动提取规律。数据 + 答案 → 模型

模型训练完成后，机器把习得的规律用于新样本预测：房价、销量、点击、欺诈、流失、图像类别等。

### 数据、特征、标签、模型

1. 进入模型的数据
   - **样本**：一条记录，一个用户、一套房子、一封邮件
   - **特征**：描述样本的输入变量
   - **标签**：模型要预测的目标输出
2. 算法与模型的区别
   - **算法**：学习方法，如线性回归、决策树
   - **模型**：学习结果，如一组权重、一棵树
   - 同一种算法，在不同数据上训练得到不同模型

> **提示**
> 机器学习的第一步，是把问题翻译成「特征 → 标签」的学习任务，而不是挑选算法。

## 监督学习：有答案的学习

训练数据既有输入，也有正确答案，模型学习从输入到标签的映射。

### 回归 Regression

预测连续数值。

- 适用对象：房价、销量、收入、温度
- 常用模型：线性回归、决策树回归、随机森林回归、GBDT

### 分类 Classification

预测离散类别。

- 适用对象：垃圾邮件、流失用户、猫狗
- 常用模型：逻辑回归、KNN、朴素贝叶斯、SVM、树模型

### 典型算法

1. **线性 / 逻辑回归**：简单易解释，训练快。线性回归输出连续数值，逻辑回归输出类别概率。是深度学习的基础
2. **决策树**：通过一系列判断规则预测，直观易解释，容易过拟合。是随机森林和 GBDT 的基础
3. **KNN**：根据最近的 K 个邻居投票。思想简单，但预测慢（要和所有训练样本比距离），对特征尺度敏感
4. **朴素贝叶斯**：基于概率和特征条件独立假设。常用于邮件分类、新闻分类、情感分析
5. **SVM**：寻找最大间隔分类边界，核函数可处理非线性，适合中小规模数据
6. **树模型集成**：随机森林、XGBoost、LightGBM、CatBoost 是结构化数据的强基线

> **补充**
> KNN、朴素贝叶斯、SVM 在本系列里没有单独展开，属于「知道它们解决什么问题、什么时候该想起来」的层级。在表格数据上，它们大多已被树模型集成取代；SVM 在小样本高维（如早期文本分类）场景仍有价值。

## 模型训练：从业务问题到可用模型

1. **定义问题**：明确业务目标、预测对象、成功指标
2. **准备数据**：清洗缺失值、异常值；编码类别特征；构造业务特征
3. **划分数据**：训练集、验证集、测试集，按需使用交叉验证
4. **训练优化**：定义损失函数，用梯度下降或树的分裂规则优化
5. **评估调参**：关注泛化能力，处理欠拟合、过拟合与类别失衡
6. **上线迭代**：部署，监控数据漂移，回收反馈，周期性重训

### 损失函数与梯度下降

**损失函数** 衡量预测值和真实值的差距，回归常用 MSE：

{{< math >}}
MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
{{< /math >}}

**梯度下降** 沿着损失下降最快的方向更新参数：

{{< math >}}
\theta := \theta - \eta \, \nabla J(\theta)
{{< /math >}}

- \(:=\)：赋值
- \(\eta\)：学习率
- \(\nabla J(\theta)\)：损失函数 \(J\) 对 \(\theta\) 的偏导数向量（梯度）

> **提示**
> 训练模型 = 定义目标 + 衡量错误 + 不断调参。

## 模型评估

数据集：

1. **训练集**：学习参数
2. **验证集**：选择模型与调参
3. **测试集**：最终评估泛化能力，只用一次

回归指标：

1. **MAE**：平均绝对误差，单位与目标一致
2. **MSE / RMSE**：放大极端误差，RMSE 单位与目标一致
3. **R²**：解释方差比例

分类指标：

1. **Accuracy**：整体准确率，类别不平衡时会失真
2. **Precision / Recall / F1**：按业务代价取舍误报与漏报
3. **混淆矩阵 / ROC / AUC**：全面看错误分布与阈值无关的区分能力

## 拟合问题

1. **欠拟合**：学得太少。训练误差高，测试误差也高
   - 增加特征或特征组合
   - 使用更复杂的模型
   - 减少正则化，增加训练轮数
2. **过拟合**：记住了噪声。训练误差低，测试误差高
   - 增加数据或数据增强，稀释噪声影响
   - 降低模型复杂度、剪枝
   - 正则化、早停、交叉验证

> **提示**
> 模型选择不是追求训练集高分，而是 **平衡拟合能力和泛化能力**。

## 集成学习：让模型组成团队

### Bagging：并行投票

- 有放回采样，训练多个模型
- 分类投票，回归平均
- 代表算法：**随机森林**
- 核心价值：降低方差，缓解过拟合

### Boosting：串行纠错

- 多棵树串行训练
- 后面的模型专注纠正前面的错误
- 代表算法：**GBDT**
- 核心价值：降低偏差，提升精度

### GBDT 家族：结构化数据强基线

GBDT 通过多棵树串行累加，每轮拟合当前模型最需要修正的方向（负梯度）。

1. **XGBoost**：正则化控制复杂度；一阶 + 二阶梯度；工程优化成熟
2. **LightGBM**：直方图算法提速；Leaf-wise 生长；适合大规模数据
3. **CatBoost**：原生类别特征；排序提升减少偏移；对称树推理快

> **提示**
> 面对表格数据，先建立树模型基线，通常是稳妥的起点。

## 无监督学习：从无标签数据中发现结构

1. **K-Means 聚类**
   - 预先指定 K 个簇
   - 样本分配到最近的质心
   - 更新质心，直到收敛
   - 应用：用户分群、图像压缩、异常检测
2. **其他聚类思路**
   - K-Medoids：用真实样本做中心，对异常值更稳健
   - DBSCAN：基于密度，不用预设 K，能找任意形状的簇
   - 层次聚类：形成多层级聚类树

## PCA 降维：保留信息压缩维度

高维数据会遇到维度灾难：计算成本高、数据稀疏、距离失效、过拟合。

PCA 用少数主成分代表主要信息：

- 找到数据方差最大的方向
- 把原始特征组合成新坐标轴
- 按累计解释方差选择前 K 个主成分

适用场景：高维数据可视化；去除冗余和共线性；降低后续模型训练成本。

> **提示**
> PCA 的代价是可解释性。新特征更像数学坐标，而非直观的业务字段。

## 工业实践工具

AutoML 不只是「一键训练模型」，而是一组覆盖数据探索、预处理、调参、实验管理和质量检查的工具链：

| 需求 | 首选工具 | 替代方案 | 替代场景 |
|---|---|---|---|
| 快速了解数据全貌 | `ydata-profiling` | `sweetviz` | 对比两个数据集 |
| 快速得到强健基线 | `AutoGluon` | `PyCaret` | 在 Jupyter 里逐步交互 |
| 规范预处理流程 | `sklearn.pipeline.Pipeline` | — | 必用核心，没有平替 |
| 智能搜索超参数 | `Optuna` | `Ray Tune` | 多机多卡分布式调参 |
| 实验记录与管理 | `MLflow` | `W&B` | 团队协作及深度学习场景 |
| 检测标签错误 | `Cleanlab` | 人工抽检 | 数据质量遇到瓶颈 |
| 处理类别失衡 | `imbalanced-learn` | `class_weight` | 数据量小、任务简单 |

> **提示**
> 先用 `AutoGluon` / `PyCaret` 建立基线，再用 `Pipeline` / `Optuna` / `MLflow` 把流程工程化。

> **补充**
> 模型解释常用 `SHAP`：对树模型能精确、快速地算出每个特征对每条预测的贡献，比 MDI 重要性更可靠，也能解释单个样本。模型上线后还要关注 **数据漂移**（输入分布变化）和 **概念漂移**（输入与标签的关系变化），`Evidently` 之类的工具可以做监控。

## 从机器学习到深度学习

传统机器学习提供了「从数据到模型」的完整框架，但依赖人工设计特征。

1. **传统机器学习**
   - 适合结构化表格数据
   - 强依赖特征工程
   - 可解释性强、训练成本低
   - 树模型在业界表现突出
2. **深度学习**
   - 使用多层神经网络
   - 自动学习多层抽象特征
   - 擅长图像、语音、文本、生成任务
   - 需要更多数据、算力和工程体系

两者的分界线并不在「模型多复杂」，而在于 **特征由谁来找**。表格数据的特征人能设计出来，树模型往往更好；图像、文本、音频的特征人设计不出来，只能让网络自己学。

## 结尾

回头看这个系列，主线其实很短：

1. 用 **线性回归** 建立「模型 = 参数化函数，训练 = 最小化损失」的框架
2. 用 **梯度下降** 解决「怎么最小化」
3. 用 **数据预处理、评估、拟合诊断** 解决「怎么让它在新数据上也管用」
4. 用 **逻辑回归** 把框架从回归推到分类
5. 用 **决策树 → 随机森林 → GBDT** 换一条不靠梯度的技术路线，也是表格数据的实战主力
6. 用 **K-Means 和 PCA** 看到没有标签时能做什么

下一步是深度学习：神经网络把逻辑回归一层一层叠起来，反向传播把梯度下降推广到任意深度。框架不变，只是模型变得能自己找特征。
