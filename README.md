# keleBlog

学习笔记与技术博客 —— Kafka、AI 与后端那些事

[在线阅读](https://kele0808.github.io/keleBlog/)


## 目录结构
```
keleBlog/
├── archetypes/          # 新文章模板
├── assets/              # 需要经过 Hugo Pipes 处理的资源
├── content/             # 所有 Markdown 内容
│   ├── archives.md      # 归档页
│   ├── search.md        # 搜索页
│   └── posts/           # 博客文章
├── data/                # 数据文件（YAML/JSON/TOML）
├── i18n/                # 多语言翻译
├── layouts/             # 自定义模板（覆盖主题）
├── static/              # 直接拷贝到根目录的静态文件（favicon 等）
├── themes/PaperMod/     # 主题
├── hugo.toml            # 站点配置
└── .github/workflows/   # GitHub Actions 自动部署
```
